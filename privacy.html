03

Data Storage & Security

3.1 Where We Store Your Data

Local Storage (On Your Device):

  • SharedPreferences: User preferences, authentication tokens, theme settings, language preferences
  • Hive (Local Database): Cached recipe categories, offline content, temporary data

Remote Storage (Cloud Servers):

  • MongoDB Database: User accounts, recipes, social interactions, activity data, achievements
  • Cloud Storage: Recipe images, profile pictures, user-uploaded media
Data Retention: We retain your personal data only as long as necessary to provide our services and fulfill the purposes described in this Privacy Policy. You can request deletion of your account and data at any time.

3.2 Security Measures

We implement appropriate technical and organizational measures to protect your data:

  • Encryption: Passwords are encrypted using industry-standard algorithms
  • Authentication: JWT-based authentication with automatic token refresh
  • Secure Communication: HTTPS / SSL encryption for all data transmission
  • Access Controls: Limited access to personal data by authorized personnel only
  • Regular Monitoring: Continuous monitoring for security vulnerabilities and threats
Security Notice: While we strive to protect your personal data, no method of transmission over the internet or electronic storage is 100% secure. We cannot guarantee absolute security but continuously work to improve our security practices.
